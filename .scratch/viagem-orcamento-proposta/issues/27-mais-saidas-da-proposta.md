# 27: More Proposta outputs

**What to build:** More ways to present the same Versão:
- **Detail on request:** prices per Dia or per service, with a Desconto shown when there is one, never the Margem or the Ajustes manuais.
- **B2B notes:** notes and recommendations for the agency's seller (questions to ask the traveller, suggestions).
- **Light B2B output:** a text summary of services and values, for agencies that don't need a deck.
- **Proposta genérica:** sent fast when the briefing is incomplete, marked as needing adaptation.
- **Generic names before confirmação:** Atrações by generic name ("mercado de peixe") before confirmação, with the detailed Roteiro after, once Atrações exist.
